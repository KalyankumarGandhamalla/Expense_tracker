# 💰 Expense Tracker (with Dark/Light Mode)

A simple, responsive web app to track expenses by category and visualize spending using a pie chart.  
Built with **HTML**, **CSS**, and **JavaScript** (no frameworks required) and uses **Chart.js** for the chart.


## ✨ Features
- **Add, edit, and delete** expenses with description, amount, and category.
- **Inline editing** for quick updates.
- **Dark / Light theme toggle** with preference saved to `localStorage`.
- **Persistent data**: expenses are stored in the browser’s `localStorage`.
- **Responsive design**: works on desktops, tablets, and phones.
- **Pie chart** visualization of spending by category.

## 🌑 Dark/Light Mode

Click the 🌙/☀️ toggle button at the top-right corner to switch themes.

Your choice is remembered across page reloads using localStorage.
